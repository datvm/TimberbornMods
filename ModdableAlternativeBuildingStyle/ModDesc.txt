This mod provides an unified Alternative Building Style option for designers. I made this after noticing many recent mods making each style a separate building with the same function. With this mod, you build the same building, then choose the style you want from a menu. It is completely cosmetic and does not affect gameplay.

Beside the built-in styles provided by this mod, try [url=]Alternative Faction Building Styles[/url] to allow each faction to use the other faction's building style.

You simply choose a supported building, you should see the new Alternative Style option in the panel on the right. You can change the style anytime, or choose Original to revert back to the default model. It only affects one building, so you can have multiple buildings of the same type with different styles right next to each other. The game's copy function works as expected.

[h1]Designer Guide[/h1]
Please see [url=]Designer Guide[/url] on how to add your own alternative styles to this mod. This mod itself provides a few built-in style as examples as well with typical use case, like animations (Inventor) or custom behaviors with specific child components (Floodgate, Gravity Battery).

Note that certain buildings may not be suitable for alternative styles (Wonder), though it probably could be solved with custom script if you are dedicated.

[h1]Known Issues[/h1]
- Changing the model may not tint the selection color.
- Long loading time the first time you load a new material (for example, loading an IT model for FT).
- If you choose an alternative style before finishing the construction, it will only show the construction base.

I tried to fix many types of buildings manually, like the Floodgate. If you find any issue I miss, please let me know.
